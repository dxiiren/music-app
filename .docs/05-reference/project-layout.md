# Project Layout

> **TL;DR** Standard Vite + Vue 3 SPA: config at the root, app code in `src/` (views own
> pages, components are shared UI, stores hold cross-page state, includes hold app-wide
> wiring), Cypress in `cypress/`, the original HTML mockups in `template/`, and the
> onboarding kit as `justfile` + `setup.ps1` + `.docs/` + `.claude/`.

## Root

| Path | What it is |
| --- | --- |
| `index.html` | Vite entry; loads Roboto + Font Awesome from CDNs; `<div id="app">` |
| `vite.config.js` | vue + vite-plugin-pwa (dev SW enabled, autoUpdate) + vue-devtools + Tailwind v4; `@` → `src/`; rollup visualizer commented out |
| `vitest.config.js` | merges vite.config, adds jsdom environment |
| `cypress.config.js` | e2e spec pattern + baseUrl `http://localhost:4173` |
| `eslint.config.js` | ESLint 9 flat config: vue + vitest + cypress + prettier-skip |
| `.prettierrc.json`, `.editorconfig`, `jsconfig.json` | formatting + editor + `@/*` path mapping |
| `package.json` / `package-lock.json` | npm; scripts documented in [`commands.md`](commands.md) |
| `justfile`, `setup.ps1` | day-2 recipes + one-time machine bootstrap |
| `CLAUDE.md`, `.claude/`, `.mcp.json.stub` | Claude Code project brief, skills, MCP stub |
| `stats.html` | committed rollup-visualizer bundle report (stale snapshot; regenerate via the vite.config visualizer if needed) |
| `dev-dist/` | PWA **dev** service-worker output — tracked but regenerated by every dev run; don't commit churn |
| `template/` | the original static HTML mockups (index/manage/song) the Vue views were built from — reference only |
| `public/assets/img/` | header/introduction/song images + the PWA icon |

## src/

| Path | What it is |
| --- | --- |
| `main.js` | boot: CSS, SW registration, NProgress; `createApp` gated inside `onAuthStateChanged` |
| `App.vue` | shell: AppHeader + transition-wrapped `<router-view>` + AppPlayer + AppAuth |
| `router/index.js` | `/`, `/about`, `/manage` (requiresAuth), `/song/:id`, catch-all → home |
| `views/HomeView.vue` | playlist: cursor-paginated Firestore query + infinite scroll |
| `views/ManageView.vue` | auth-only: Upload + editable list of your songs; unsaved-form leave guard |
| `views/SongView.vue` | song header + play, i18n price/comment-count, comment form + sorted list |
| `views/AboutView.vue` | static |
| `components/AppHeader.vue` | nav, auth modal trigger, logout, locale toggle |
| `components/AppAuth.vue` + `Auth/` | modal with LoginForm / RegisterForm (VeeValidate) |
| `components/AppPlayer.vue` | persistent bottom player bar bound to the `player` store |
| `components/Upload.vue` | drag-drop multi-file upload → Storage, progress bars, cancel on unmount |
| `components/SongItem.vue`, `CompositionItem.vue` | playlist row / manage-page editable row |
| `components/Base/Button.vue` | auto-registered as `BaseButton` by `_global.js` |
| `components/basic.vue` | scaffold leftover (unused) |
| `components/__tests__/` | 9 Vitest specs + `__snapshots__/` |
| `stores/` | `user.js`, `player.js` (Howler), `modal.js`, `counter.js` (unused scaffold) |
| `includes/firebase.js` | THE Firebase bundle — services (initialized only when configured), SDK re-exports |
| `includes/firebase-config.js` | env-driven config: reads `VITE_FIREBASE_*`, empty-object fallback |
| `includes/not-configured.js` | the "Firebase not configured" setup banner `main.js` renders when unconfigured |
| `includes/validation.js` | global VeeValidate plugin: rules + messages |
| `includes/i18n.js` | vue-i18n: `ms` default, `en` fallback, currency formats |
| `includes/helper.js` | `formatTime` (player timers) + random helpers |
| `includes/progress-bar.js` | NProgress on route change |
| `includes/_global.js` | globs `components/Base/*` into global `Base*` components |
| `directives/icon.js` | `v-icon` Font Awesome class helper |
| `locales/en.json`, `locales/ms.json` | translations |
| `assets/` | `base.css`, `main.css` (Tailwind v4 entry), logo |
